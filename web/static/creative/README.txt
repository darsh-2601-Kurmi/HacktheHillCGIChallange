Home page theme: Start Bootstrap Creative v7.0.7 (MIT), https://github.com/StartBootstrap/startbootstrap-creative
Laid out as in the theme's dist/ folder. css/styles.css and js/scripts.js are the theme's files, unchanged.
The theme loads Bootstrap's JS, Bootstrap Icons, SimpleLightbox and two Google fonts from CDNs. The same files are
kept here instead so the page works offline:

  js/bootstrap.bundle.min.js        Bootstrap 5.2.3 (MIT)            LICENSE-bootstrap.txt
  css/bootstrap-icons.min.css       Bootstrap Icons 1.11.3 (MIT)     LICENSE-bootstrap-icons.txt
  js/, css/simpleLightbox.min.*     SimpleLightbox 2.1.0 (MIT)       LICENSE-simple-lightbox.txt
  css/fonts/merriweather*.woff2     Merriweather, Merriweather Sans (SIL OFL 1.1), OFL-*.txt; css/fonts.css
